# Исходный аудит локального дерева

До реализации: HEAD `0573113c860c684494371e46d6f98ec946cd6562`, существующие незакоммиченные изменения и удалённые файлы перечислены в `initial-status.txt`. Это локальный HEAD, не GitHub main. В `xml-inventory.json` для каждого из 303 XML записаны контрольная сумма, категория, правила загрузки 1.6/1.7, именованные Def и одноимённые кандидаты Checker. Совпадение имени не доказывает право перезаписи: неподтверждённое происхождение считается ручным. Все 303 XML разбираются; повторных именованных Def среди статических Def-файлов не найдено. При повторной проверке подтверждено: `DLC/Royalty` указан в LoadFolders с условием `Ludeon.RimWorld.Royalty` для обеих версий.

Таблица содержит 414 строк Animals, 414 Animals CE и 12 профилей; шесть помечены Has antivenom. Заголовки CO/CQ и бонусы J2/J3 подтверждены. Формулы BS/BK уже включают бонусы и ограничение размера. Таблица не изменяется. `Strategies.xml`, `MonitorVenom.xml` и прежний package builder уже удалены пользователем до начала; отдельного патча ConstrictibleBody в рабочем дереве не обнаружено. Обычные видовые XML содержат часть PredationStrategy/Burrower/TreeClimber, но Constrictor и VenomSample пока не интегрированы в генераторы. Текущие статические образцы/препараты содержат только Cobra/Viper.

`checker/generated_patches/move_xmls.py` использует жёсткий MAPPINGS, записывает в каталоги животных, перезаписывает без учёта владельца, не поддерживает dry-run и имеет запасной корень. Происхождение существующих XML не размечено; удаление и замена допустимы только по точным доказательствам или с манифестом владения. В `AnimalConstriction.cs` удержание только после охоты, на соседних клетках, сбрасывается при Downed/Stunned и использует порог по входному DamageInfo; эти факты не соответствуют новому контракту. Контрольные атаки и ловля после save/load требуют реального игрового тестирования.

План: единый ввод листов и проверка цепочек; генерация препаратов по HediffDef; назначение расширений по строкам Animals; манифест и безопасная маршрутизация; выделенный анатомический патч; изменения боя/охоты и проверки; отдельный отчёт об удалённых XML и тестах. Бонусы CombatPower не вычислять в коде. Риски: старые сохранения с существующими Cobra/Viper DefName, условные DLC/CE и отсутствие метаданных старых результатов. Никакие неподтверждённые файлы не очищать автоматически.
