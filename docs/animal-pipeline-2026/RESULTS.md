# Результат работы с локальным ZoologyFramework

## Данные, генерация и XML

Данные прочитаны из Google Sheets AnimalStats — WORKING: 414 строк Animals, 414 строк Animals CE, 12 профилей и 15 производителей образцов. Профили объединяются по HediffDef. Текущий каталог формирует шесть образцов, шесть препаратов и шесть рецептов: Cobra, Viper, Arachnid, Scorpion, Atispec и Barb. Cobra и Hydra используют один образец и один нейтрализуемый Hediff. Поля цветов скопированы в графические данные; общие свойства заданы двумя абстрактными родителями. Существующие DefName Cobra и Viper сохранены. Таблица не изменена; бонусы CombatPower заново не начисляются.

В обычных видовых патчах созданы Constrictor и VenomSample по данным таблицы. Статический патч ConstrictibleBodies переносит прежнее покрытие схем тела из локального HEAD. Созданы манифест вывода и общий mover с проверкой LoadFolders, хешей владельца, dry-run и очисткой принадлежащих генератору устаревших результатов. При начальной миграции существующие файлы сопоставлены с источниками по идентичному содержимому и сохранённым хешам. Реальная область реализации и её ограничения перечислены в OPEN_ISSUES.md.

Исходный список состояния дерева — initial-status.txt, исходная инвентаризация XML — xml-inventory.json, состояние каждого текущего XML — xml-disposition.csv. Перечень текущих изменений Git и новых файлов — FILE-MANIFEST.txt. Некоторые файлы уже были изменены до этого задания; их исходный статус сохранён отдельно.

## Проверки

- `python -m unittest discover -s tests -q` из checker: 63 теста, OK (checker-tests.txt).
- Google Sheets: фактическое авторизованное чтение и полная генерация. XLSX: фактическое чтение трёх листов из временного снимка реальных значений; TSV с явным каталогом прочитан, отсутствие каталога вызвало ожидаемую ошибку.
- Полные прогоны генератора с разными PYTHONHASHSEED: 84 файла, побайтно одинаковые содержимое и пути после исправления порядка абстрактных патчей. `python checker/generated_patches/move_xmls.py --dry-run`: план из 84 действий, проверка хешей подтвердила отсутствие изменения файлов. Повторный реальный перенос: 84 SKIP.
- Все 305 XML разбираются; непосредственных повторных именованных Def одинакового типа не обнаружено. Это не доказывает корректность всех условных конфигураций и внешних ссылок.
- Сборки прошли: `dotnet build Zoology/Source/ZoologyMod.csproj -c Release -p:RimWorldVersion=1.6 -p:OutputPath=codex-build/implementation/build16 --nologo -v:q` и `dotnet build Zoology/Source/ZoologyMod.csproj -c Release -p:RimWorldVersion=1.7 -p:OutputPath=codex-build/implementation/build17 --nologo -v:q`; обновлены загружаемые DLL. Изолированный запуск — `tests/RimWorld17/run-validation.ps1 -Run` и тот же вызов с `-CombatExtended` в подготовленных профилях. Первый полный Vanilla-прогон: 161 PASS; повторный полный прогон на иной случайной карте имел FAIL и исключение, см. OPEN_ISSUES.md.
- Изолированные Vanilla и CE: общая клетка, потеря сознания, пробуждение, порог освобождения и события без инструмента/с нулевым уроном; реальные анаконда, капибара и корги с соседней клетки; применение всех шести препаратов. CE в установленной копии отмечен игрой как несовместимый с 1.7.
- Сравнение 419 животных: `tests/RimWorld17/run-benchmark.ps1 -Mode no-mod -Repeats 3 -Run`, а также с `-Mode baseline` и `-Mode updated`. См. performance-no-mod.txt, performance-baseline.txt и performance-updated.txt. Требование равной производительности с базой не подтверждено.

Оставшиеся ограничения, включая незавершённую единую маршрутизацию всех видов XML, перечислены в OPEN_ISSUES.md.
