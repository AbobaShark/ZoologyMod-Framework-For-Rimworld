RimWorld patch compactor
========================

GUI
---
Enable:
  Compact generated patches (fewer XPath operations)

When enabled, the fixer compacts only XML files successfully generated by the
current run, immediately after generation. Existing/stale files in
"generated_patches" that were not produced by that run are not touched.
Files are rewritten in place; patches from different XML files are never
combined.

Standalone
----------
From the checker folder:

  py rimworld_patch_compactor.py

With no arguments it recursively compacts ./generated_patches in place.
You can also pass one or more XML files or folders:

  py rimworld_patch_compactor.py "generated_patches\\Core"

The command prints before/after byte, PatchOperation and XPath counts.
